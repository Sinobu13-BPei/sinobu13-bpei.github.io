3. COVID特需と需要抑制を分けて読む

COVIDは「医療機器市場を一様に押し上げた」わけではない。装置ごとに逆方向の影響が発生したため、2020–21年を単純CAGRで外挿すると市場を誤認する。

2019

消費増税前の前倒し更新・まとめ買い。高値を構造成長率の起点にしない。

2020

外来・選択的検査抑制。診療所US、内視鏡、一般撮影などは下振れ。

2020 特需

感染対策・補助金により回診用X線など一部機器は上振れ。一般撮影市場とは分離。

2021

CTは補正予算による一時的特需。MRIは2020年延期案件の反動回復。

2022–25

特需剥落、更新延期、資材・価格上昇、収支悪化が混在。IB×寿命で正規化。

モデル処理： 2020–21の一時的な販売ピーク/谷を将来成長率に直線外挿せず、Installed Base × 更新周期 × 更新圧力へ戻して2026基準を構築。

Clinic Marketへの読み替え｜3層TAM

① Core Device TAMCT / MRI / US / XR / 内視鏡 / DEXA / Mammo / 生体情報 / IT。本ページの1,242億円モデルは主としてこの層。
② Workflow TAMPACS / Viewer / Cloud / AI診断支援 / Remote Reading / Operation Optimization。
③ Patient Lifecycle TAMPOCT / Wearable / Remote Monitoring / Telehealth / SaMD。予防・慢性疾患管理・予後まで拡張。
本レポートの分析（みずほ資料からの読み替え）： 診療所は単なる「約10万施設の機器販売先」ではなく、画像・検査・Vital・処方・Follow-up Dataを生む分散型Healthcare Networkとして評価する余地がある。その場合、Installed Base × 更新年で測るCore Device市場に、WorkflowとPatient LifecycleのRecurring/Software市場を重ねる必要がある。

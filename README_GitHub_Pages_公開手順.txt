# 森若一族の歴史 GitHub Pages 公開パッケージ

## 含まれるもの
- index.html
- .nojekyll
- assets/（10枚の画像、正確な日本地図2点、棒グラフ、構成比グラフ、タイムライン）

## GitHub Pages 反映手順
1. `sinobu13-bpei.github.io` リポジトリを開く
2. 既存ファイルを残す場合はバックアップ
3. このパッケージの中身をそのままリポジトリ直下へアップロード
4. `index.html` を置き換える
5. `assets` フォルダごとアップロード
6. Commit changes
7. Pages が反映されるまで 1〜3 分待つ

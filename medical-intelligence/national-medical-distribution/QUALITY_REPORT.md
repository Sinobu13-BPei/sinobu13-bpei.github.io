# 2026-10-27 地図・グラフ表示不具合の品質検証

## ユーザー申告
GitHub Pages 上で「全国47都道府県と7つの事業環境」の地図領域が空欄になり、外部地図ライブラリを利用できない旨の代替メッセージが表示された。

## 技術的原因
- Leaflet と Chart.js を `defer` で読み込んでいたのに対し、ページ本体は遅延処理の完了より前に初期化することがあった。
- 初期化時の `window.L` / `window.Chart` 判定が偽になり、地図・グラフの正常描画処理が通らなかった。
- ライブラリ不達時の代替表示が説明文だけだったため、大きな空白になった。

## 是正措置
1. `DOMContentLoaded` 後の初期化へ変更（defer外部スクリプトの実行完了後）。
2. Leaflet 利用不可時、代表都市7地域を示す選択可能な日本列島概略SVG地図に切替。
3. Leaflet の地理院タイル読み込みが複数失敗した場合、静的地図へ自動切替。
4. Chart.js 利用不可時、売上棒グラフ・業態構成・地域仮説評価をHTML/CSSベースの棒・構成図に切替。
5. 地図用地域説明・企業DB・金融／リース／レンタル分類などの既存データは保持。
6. `regionStrategies` の重複カード表示を非表示にして空白を削減。

## 検査
- 公開用HTMLの JavaScript 構文検査：PASS
- ライブラリ無し環境の模擬DOM初期化：PASS（静的地図、4グラフ、企業25件・金融11件・地域7件の表示）
- ライブラリ有り環境の模擬DOM初期化：PASS（Leaflet・Chart.js分岐、4グラフ描画呼び出し）
- 金融検索・絞込み・リセット操作（前回）：PASS
- GitHub上のJSON・CSS・JSと公開用HTMLの同期：PASS
- GitHub Pages実ブラウザ、外部CDN・地理院タイルの全環境到達性：未確認

### データの読み方
SVG地図は**概略地理**であり、行政界・代表都市の正確な標高・縮尺、医療機関や販売拠点を示さない。Leaflet利用時の地図タイルは国土地理院の標準地図（地理院タイル）。
売上高と従業員数はそれぞれ開示基準が異なる。市場シェアや医療機器取扱高との混同を禁ずる。

## 更新・注意

## 2026-10-27追加：医療圏・医師会ごとの施設数
- 8二次医療圏の一般診療所、病院、歯科診療所（令和5年10月1日、大阪府第2表から43市町村を重複なしで再集計）
- 43市町村の施設明細、2025年3月31日の大阪市24区の一般診療所・病院・歯科診療所数（大阪市統計原表）
- 大阪府医師会公式一覧に掲載する64団体（地域57＋大学/職域7）と各団体の公式掲載ウェブサイト
- 医師会ごとの参考施設数は地域の行政統計であり「医師会会員施設数」ではない。
- 東大阪市は布施・枚岡・河内3医師会が同じ市域の数値を参照。大阪市の北区・中央区もそれぞれ2医師会が同じ区域の施設数を参照。個々の医師会施設数として合算しない。
- 大学・職域医師会は地理的な対象区域を持たないため施設数を計上しない。
- 地域別施設数の合計：病院502、一般診療所8,877、歯科5,411（2023年）；大阪市区別：病院172、一般診療所3,911、歯科2,172（2025年）。

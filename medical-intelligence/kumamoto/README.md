## データと品質の注意点
2025年人口確定値1,677,302人と2026年9月推計1,671,164人は熊本県公表値。二次医療圏の2024人口と2040人口予測、2026年病床機能見込と2025年必要病床は公開二次集計値のため厚労省・県原表との今後の照合が必要。2026年医師偏在指標は厚労省公表値の再集計。設置機器台数・販社シェアを未検証のまま掲出しない。
病床2026見込・病床2025必要量は定義と時点が異なるため直接不足・過剰と判定しない。10地域優先度スコアは当サイト独自の定性的仮説であり、売上高や確定需要ではない。
住所検索には各施設の名称・住所を用い、地理院地図の緯度経度は参照用の概略位置。個別の正確な建物位置や医療圏境界を表さない。

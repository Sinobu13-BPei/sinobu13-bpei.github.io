## 出典・数値の注意
2024年病床機能報告の許可病床計は13,410床、地域医療構想の2025年必要病床計は11,037床（宮崎県公表値）。
**宮崎県の地域医療構想資料は医療圏別の機能別掲載値を個別に合算すると11,048床となり、県計11,037床と11床の差があります。** 本ページでは県計は公表値11,037床を採用し、地域別セルは公表値どおり掲載、差があることを明記します。差分を施設投資や削減目標に換算しません。
2030/2040年の機能別推計も区分の合計と公表県計にごく小さい相違があり、出典表の小計を訂正せず利用しています。
2026年4月医師偏在指標は厚生労働省の一次資料を採用しています。
高齢化率2025年34.4%、県人口2026年9月1日1,008,190人は年次が異なります。
各医療圏のスコアリングは内部販売実績とは独立した公開情報に基づく**分析者仮説**です。
医療機関のGSIリンクは市域概略中心へのリンクで、施設敷地の正確なGPSとは異なります。

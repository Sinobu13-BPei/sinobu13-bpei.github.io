# 兵庫県 Medical Intelligence (2026-10-27)

公開サイト: https://sinobu13-bpei.github.io/medical-intelligence/hyogo/

## ファイル
- index.html — ページ
- assets/style.css — スマートフォン対応のスタイル
- assets/app.js — Chart.js、Leaflet 地理院タイル、地図リンク、施設一覧、優先度モデル
- data/regions.json — 8医療圏の病床機能・医師偏在指標、定性評価

## データについて
**2025年必要病床数は2016年策定需要予測に基づく計画推計**であり、2025年時点の現況ではありません。比較に使う病床機能報告は2021年度です。2025年度分の最新原表は県公式を参照。

人口 5,292,593 人は兵庫県の2026-09-01推計。社人研2050年の436万人は別年次の将来推計。

医療圏スコアは独自定性モデル。数値の補完は禁止。地図座標は代表点・施設周辺の概略であり正確な建物地点ではありません。

特定メーカー名・内部売上・取引条件・顧客単位の営業情報は掲載していません。

## チェック
- 静的HTML + CSS + JS; GitHub Pagesで動く相対パス。
- Leaflet: 国土地理院「地理院タイル」表記を地図とフッターに記載。
- Chart.js / Leaflet はCDN利用。CDN不可の場合はチャートが空白になる可能性があります。
- HTMLの一次出典リンクと年次は index.html に掲載。
- データファイル単体はブラウザ上のfetch()で読み込み。file://ではなくWebサーバーで確認すること。

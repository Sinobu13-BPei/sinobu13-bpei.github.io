公開資料を基礎に中立的に編纂。更新日 2026-10-27。

## ファイル
- index.html: 本文（静的）
- style.css: レスポンシブスタイル

- data/market.json: 圏域・病床・人口・医師偏在・ソース・場所リンク

## データの取扱い
- 病床機能報告の「現状」と必要病床数の推計は異なる指標として表示。
- 地理院リンクの位置は自治体中心の概略点であり施設座標を保証しない。
- 将来人口・独自スコアは推計と明記。装置台数の未確認値は非表示。
- 県内市場の非公開販売額・販社シェア・顧客リスト・社内戦略は公開しない。

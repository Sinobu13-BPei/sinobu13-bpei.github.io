## 重要なデータ定義
- 病院/一般診療所数の最新比較は2025年10月1日、厚労省医療施設調査。全国と隣接県を同一年次で比較。
- 二次医療圏病床機能は2025年7月1日、鳥取県・島根県公表の自主報告。鳥取6,675床、島根7,417床。一般・療養病床の病床機能報告の集計であり全病床数とは異なる。
- 2024年病床機能報告の比較表は履歴として保存。
- 島根の2025年「必要病床数」は古い地域医療構想で2016年に推計された値。2025年実績・最新必要数ではない。
- 二次医療圏人口は2020年国勢調査を基礎とする過去資料。2030/2040/2050は社人研2023年推計であり観測値ではない。
- 2024年の医療施設従事医師数は鳥取1,697、島根2,014。医師偏在の最新2026年4月版は原表参照。
- CT/MRI/US/PET/リニアック/血管撮影/透析などの県別設備台数・全国順位は、公表施設票をダウンロードして集計しない限り示さない（今回未集計）。
- 市街地付近の地理院地図リンクは施設の正確な位置ではなく参考点。Googleマップは施設名＋所在地検索で実際の位置を開く。
- 地図背景は国土地理院の地理院タイル。地図上のマーカーは医療圏代表都市であり個別病院の正確な座標ではない。
- PEST/3C/STP/4P/4C/VRIO/5F/KSFや医療圏優先度は事実ではなく分析者の仮説。重み合計100%、評価スケール1〜5点。

09 / STRATEGY TOOLKIT

PEST → 3C → STP → 4P → 4C → VRIO → 5 Forces → KSF

中立的な医療機器商社を想定した仮説設計。機器メーカーや特定販売会社を推奨・批判するものではありません。

PEST / マクロ環境

P：第8次医療計画・医師配置・地域医療構想。E：人口減、設備投資余力・物価。S：高齢化、通院交通・在宅。T：高効率画像診断、遠隔支援、医療DX・サイバー対策。

3C / 市場構造

Customer：病院/診療所/在宅の医療継続性。Competitor：広域卸、地場商社、メーカー直販、共同利用サービス。Company：商社自身の保守・物流・専門人材・財務・顧客接点。

STP / 優先顧客

S：大学・公立急性期／民間病院／診療所／へき地拠点。T：高稼働更新、経営改善、医療BCPが明確な施設。P：メーカー非依存の医療ワークフロー設計・継続支援。

4P / 提供設計

Product：機器＋IT＋教育＋保守。Price：導入費だけでなくTCO。Place：地域技術者・緊急物流。Promotion：臨床課題別の説明と透明な比較資料。

4C / 顧客価値

Customer value：検査品質・継続性。Cost：患者/施設の負担。Convenience：保守・相談・予約。Communication：情報開示と多職種協働。

VRIO / 持続可能な強み

価値：安全な供給・復旧。希少性：地域密着の保守網。模倣困難性：病診連携と複数専門職の関係。組織：部品在庫・人材・KPI・BCPが制度化されていること。

5 Forces / 競争要因

病院の交渉力、高額機器メーカーの供給支配、卸間競争、共同利用/遠隔読影による代替、参入障壁（薬機法・修理・保守拠点）。各圏域で強度が異なる。

SWOT / 地域横断

S：大学・公立中核網、広域道路。W：人口減・アクセス格差。O：更新・連携・BCP。T：震災、豪雪、投資制約・サプライチェーン。

医療圏の優先度スコア：評価軸・重み

独自分析：各軸1〜5点、重み付き合計を100点換算。高スコア＝売上・予算・受注確率ではなく、調査/提案着手の優先度。恣意性を抑えるため各軸を表示し、将来は実データにより更新する。

短期 / 0〜90日

12圏域の中核施設・診療所・修理拠点・配送経路を公開情報で台帳化。機器設置年・稼働率・更新計画を施設ヒアリングで確認。奥能登の構想と道路復旧を月次確認。

中期 / 3〜12か月

県境横断の保守SLAと予備機配置PoC。高度医療3極と過疎・BCP地域で別々の共通価値提案を試験し、教育・画像共有も検証。

中長期 / 1〜3年

病院再編・診療所承継・共同利用の公募を追跡。部材と人材の多重化、契約型保守・更新時TCOを標準化する。

CRITICAL SUCCESS FACTORS / KSF

勝ち筋を定める5条件

  1. 需要を県平均でなく二次医療圏・診療科・稼働条件で把握
  2. 物流と保守を県境横断で設計し、現地対応時間を検証
  3. 装置・IT・教育・保守を一体化しTCOを可視化
  4. 医師不足・災害・病院再編に強い代替手段を用意
  5. 公開データ・現地確認・独自推計を厳密に区別する

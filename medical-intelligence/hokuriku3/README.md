## 公開データの境界

- 2020年人口は国勢調査実績。2050年人口は社人研2023年推計。実績と推計を混同しない。
- 3県で病床報告の年次が異なる。富山・石川の2025年病床報告と福井の2024年病床報告を直接合算して最新年度の北陸総計とは称さない。
- 2025年「必要病床数」は地域医療構想の過去推計。最新の病床機能報告と単純差引した結果を「余剰」「不足」と断定しない。
- CT/MRI設置密度は旧年次の既存公開資料参照値。全国比較を含め最新同一定義での原表再抽出が必要。
- 12医療圏優先度は当サイト独自の仮説指標、医療需要や受注を実測したスコアではない。
- 地図の座標には県・市町代表点など概略位置を含む。「Googleマップ」は施設名・住所検索、「地理院地図」は座標を表示する。
- 公開企業名と拠点は事業者ウェブサイトを参照。販路シェアや顧客関係を推定していない。
- 公表できない市場シェア・顧客商談・社内売上見込・販売条件などは含まない。

## 操作方法

1. 3県の人口・2050年推計を比較し、二次医療圏セクションで県と医療圏キーワードを選択する。
2. 病床グラフと優先度を確認し、各県の第8次医療計画リンクから原表を確認する。
3. 地図セクションで「大学病院」「中核病院」「医師会」「県庁」「保健所」を選択する。
4. 流通・ロジセクションでは道路復旧や現場保守網を優先し、物流の実測・到達時間をまだ作成していないことに留意する。
5. 出典一覧はリンク・年次付き。必要に応じて正式最新年次で再検証する。

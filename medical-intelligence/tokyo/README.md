# 東京都 医療市場総合分析 2026–2030（公開版）
公開想定URL: https://sinobu13-bpei.github.io/medical-intelligence/tokyo/

## 対象
東京都・23区（区部7医療圏）・多摩（5医療圏）・島しょ（1医療圏）の全13二次保健医療圏。医療機器商社の中立的立場で作成する、公開一次資料優先の研究。最終データ更新 2026-10-26。

## ファイル構成
- `index.html`: 全文、地域比較表、大学、医師会、戦略、出典、免責
- `style.css`: レスポンシブUI、明度と可読性
- `data.js`: 13医療圏・大学・代表病院・出典、年次付き公表データ
- `app.js`: Chart.jsによるグラフ、Leaflet + 国土地理院タイル、13圏域検索、地点リンクと独自スコア

## 計画と調査の判断
1. 都道府県・医療圏境界の明確化と病床・人口の母集団の統一
2. 東京都（人口・病床・保健医療計画・医療機器）、厚労省（医師偏在指標・地域医療構想・DPC）、社人研（将来推計）、東京都医師会（地区医師会）を優先
3. 添付データブックなどを調査項目の発見に利用。ただし商流、販売計画、市場推計、営業割当、医療機関別取引情報、著作権保護された民間調査表や内部資料は一般公開しない。
4. 2020/2023/2024/2026年の異なる年次のデータを混同しない。人口10万人当たり・調整人口10万人当たり・病床数など単位を明示
5. 推論（課題・3〜5年機会・優先スコアリング）を実測値と区別

## 用語とデータ年
- 人口：2026年9月1日（東京都）
- 病院633・一般診療所15,146：2024年10月1日、東京都「東京の福祉保健2026」所収の医療施設調査（区部420・11,850）
- 前年比較：2023年は病院637・一般診療所14,894
- 2024年度病床機能報告：13圏域の許可病床と自己申告病床機能（合計106,972床）
- 医師偏在指標：2026年4月公表（都県単位と二次圏域単位）
- CT/MRI/PET/マンモ・体外照射：2020年原データ、東京都保健医療計画から調整人口10万対の比較値
- 2025必要病床113,764床：2016年に計算された過去の推計。2024許可病床との比較だけで需給不足を判断しない

## 地図の正確性
- Leafletの地理院タイルを利用。医療圏のマーカーは便宜的中心点で、行政境界や病院所在地ではありません。
- 病院・医学部はGoogleマップを名称・住所の検索で開きます。
- 地理院地図は圏域の概略中心に接続し、施設精密座標と誤認しないよう画面内に注意書きしています。
- 正確な施設座標・二次医療圏境界ポリゴンは追加検証が必要です。

## 2026-10-26の追加資料反映 / Rev2
- 補足の東京都商用市場資料、JAHID2023会員名簿、病床・DPC集計、TMG・AMG・JCHO・NHO・JH病院一覧、診療所横断商談資料を照合。
- 行政一次資料で2024年の施設数を確認し、2023年との比較グラフ、23区の施設比率を追加。
- JAHIDは2023年の古い一覧数ではなく2026年10月21日の協会公式公表構成員924社・企業会員141社・賛助会員118社・団体43を採用。
- 病院グループの公開情報で裏付けられる東京都内のTMG9、AMG2、JCHO5、NHO4、計20病院を地域別検索表で掲載。
- 2026年度病床数適正化緊急支援事業の厚労省・東京都公式資料へのリンクと政策上の注意点を追加。
- 添付の病床サマリーは区西北部1,496床など部分集計を含み、東京都の公式2024年度区西北部14,431床と一致しないため不採用。
- 添付DPC表で「完結率」が100％を超える場合、実際は所在地症例数と患者住所地症例数の比の可能性がある。「地域内自己完結率」の意味で公開しない。
- 機器売上・販社シェア・営業管理・有料調査の表や画像、非公開の推計台数は一般公開しない。
- JH関連資料には2025年JIHS統合前の病院名称があり、現行法人との再照合なしに転載しない。

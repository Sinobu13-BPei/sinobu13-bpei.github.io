第8次医療計画：2024～2029年度。医師確保計画の前期は2024～2026年度。[S05][S07]

2027年度補助事業意向調査：医療提供体制施設・設備整備、地域医療介護総合確保基金など。年度・募集締切・補助対象は県通知原文の確認が必須。[S15]

保健所・医療DX・広域連携

和歌山市保健所に加え、県立の海南・岩出・橋本・湯浅・御坊・田辺・新宮、串本支所を把握。地理的に長い県土では災害・感染症対応の行政窓口が分散。[S14]

08 / STRATEGY SAUCE → KSF

Where to Play × How to Win：戦略の全体像

市場を選び、どの価値で勝つかを分けて判断。以下のスコアは県公開データと地理条件に基づく独自定性評価であり、売上予測や施設の導入計画を示しません。

Where to Play｜重点領域

  1. 和歌山：高度医療、がん、救急、大学・教育病院の高度画像・医療IT。
  2. 田辺：紀南中核のCT/MRI/USの保守・長期稼働・救急診断。
  3. 新宮・有田・御坊：医師不足と災害BCP、在宅・診療所・病診連携の機器。
  4. 那賀・橋本：県境患者流動、健診、検査共同利用、外来診療所。

How to Win｜非価格競争

  1. メーカー横断で検査件数・償却年・保守・教育・更新を同じ物差しで比較。
  2. 画像診断・US・ITを単体でなく診療経路と人員課題に結合。
  3. 有事の代替機・遠隔支援・保守部品・物流を可視化したBCP。
  4. 医師会・保健所・医療圏に基づき、設備増設より共同利用・稼働率を優先。

優先順位スコアリング（独自モデル）

3C｜Customer / Competitor / Company

  • 顧客：病院の資金と人材・診療所の継承と高齢化
  • 競争：価格・機器性能だけでなく、地元保守・臨床教育・物流力
  • 商社：多メーカー比較・保守調整・地域診療の接続能力

STP｜Segmentation / Targeting / Positioning

  • S：7医療圏×病院/診療所×救急/がん/在宅
  • T：和歌山・田辺高機能／新宮・有田・御坊アクセス課題
  • P：機器導入後の継続稼働を支える中立コーディネーター

4P｜Product / Price / Place / Promotion

  • 装置＋保守＋教育＋IT一体化
  • 初期価格でなく7～10年TCO比較
  • 紀南の駆け付け網・代替機・地域拠点
  • 症例・病診連携・医療DXの実務情報

4C｜Customer Value / Cost / Convenience / Communication

  • 患者アクセスと検査継続という価値
  • 総保有コストと人的負荷の削減
  • 保守窓口・紹介検査の利便性
  • 病院、診療所、医師会、行政との対話

VRIO｜Value / Rarity / Imitability / Organization

  • V：複数メーカーの比較、BCP設計に価値
  • R：紀南の迅速保守網と医療連携は希少
  • I：関係資産・臨床育成は模倣に時間
  • O：継続運用できる支店・保守・データ体制が前提

5 Forces｜業界競争構造

  • 既存競争：地場商社／広域卸／メーカー直販
  • 買い手交渉力：公立病院入札・共同購入で強い
  • 供給者交渉力：特定機器・保守部品への依存
  • 新規参入：デジタル/遠隔系は入口が広がる
  • 代替品：紹介検査・共同利用・診断技術進展

## 統計と制約
- 2025年国勢調査・2024年病床機能報告・2026年医師偏在指標を使用
- 2025年必要病床数と2024年報告病床数は定義と年次が異なるため単純比較不可
- 社人研2023推計は2020年基準、2025国勢調査実績とは異なる系列
- 医療機器県内設置台数、全国および隣県比較は統一された原表での再集計前につき数値を非掲載
- 医師会・保健所等は名称リスト・公的所管入口として掲載。GSI施設リンクは地域代表地点近傍でありピン位置を保証しない
- 公開されていない営業データ・メーカー評価・取引情報は含まない
- UIはブラウザ内で完結、CDN障害時は文章で代替

## 継続的なQA
毎年の統計更新・外部リンク監査・モバイル実機試験・指定施設一覧の照合が必要。

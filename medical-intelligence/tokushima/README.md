# 徳島県 医療市場インテリジェンス 2026

公開ページ: https://sinobu13-bpei.github.io/medical-intelligence/tokushima/

## ファイル構成
- index.html — 日本語の公開レポート本文、過去版から引き継いだ市町村別診療所検索・病院地図、全体の情報構成
- css/style.css — 追加調査のレスポンシブレイアウト
- js/strategy.js — Chart.jsによる比較グラフ、各種出典・地図の表示、医療圏スコアの編集
- data/research.json — 公的データの整理（病床必要量と報告量、医師偏在・旧機器配置・重点機能、出典）
- README.md — この説明

## 出典とデータの区別
- 2025年国勢調査実績と2020年起点のIPSS将来人口推計を別系列で表示する。
- 2024年7月の病床機能報告と2025年必要病床量は算定方法が異なるため、差を政策的な病床削減目標と見なさない。
- 旧外来医療計画のCT・MRI台数（計画策定2020年）は**歴史的参考値**。2026年設置台数ではない。
- 医療圏別探索スコアは編集部の評価軸／初期重み（30/25/20/15/10）による独自分析で、公的統計や事業者順位ではない。
- 診療所のJMAP県合計と医療圏合計は一致しないため、出典に沿って併記する。
- 医療機器商社、薬業卸、SPD関連企業の記述は公開プロフィールに限る。社内営業情報、非公開商流、有料調査値の二次配布は行わない。

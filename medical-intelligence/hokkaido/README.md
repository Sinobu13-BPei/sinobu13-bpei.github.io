# 北海道 医療機器市場インテリジェンス 2026（公開研究版）

更新：2026-10-26

## 公開先
- [北海道版（GitHub Pages）](https://sinobu13-bpei.github.io/medical-intelligence/hokkaido/)
- [全国トップページ](https://sinobu13-bpei.github.io/medical-intelligence/)

## ファイル
- index.html：日本語のレポート本文。要約→人口・医療圏→提供体制→大学・医師会・行政→機器市場→流通→外部環境→戦略→出典。
- style.css：レスポンシブ・コントラスト・印刷・テーブル横スクロール・アクセシビリティ。
- data.js：公式医師偏在指標、21二次医療圏、人口推計、公開情報URL。医療圏別の所在地は代表市町の参考点。
- app.js：医療圏検索、医師偏在区分フィルター、CSV、Chart.js、Leaflet＋地理院タイル、Google/地理院地図。
 
## 原典の境界
- **公式値**：国立社会保障・人口問題研究所の令和5年推計、北海道医療計画・医師確保計画等。
- **分析仮説**：21医療圏の課題記述、優先度スコア、今後3～5年の機会、PEST/3C/STP/4P/4C/VRIO/5F/KSF。
- **不掲載**：社内資料の社名付き販売高・顧客別商談・未公開契約・顧客ランキング、検証未了の圏域別機器推定台数。
- **未集計**：21医療圏×4機能の病床機能報告と2025必要病床数の年次整合表、CT・MRI・US等の同年次人口当たり台数の比較。公式原表へのリンクを本文に掲載。
- **座標**：Leaflet医療圏の丸印は代表地点。施設リンクの地理院地図は市街地の参考座標であり、施設敷地の正確な座標を保証しない。

## 出典
本文の「09｜出典」に出典名、URL、対象年次を記載。データの原典と独自スコアを区別。

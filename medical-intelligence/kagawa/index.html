機器市場に対する解釈

CT・MRIは全国平均を上回る区域がある一方、小豆のCTは低い。機器密度が高い地域でも医療連携・救急搬送・検査待ち時間・装置更新年により需要は異なる。

一般診療所ではUS・内視鏡・心電計・携帯型エコー・医療ITの導入・更新・保守が中心となり得る。病院ではCT/MRI/PET・血管撮影・リニアック等の稼働率と検査件数が重要。

装置の設置台数・メーカー別シェア・稼働年数・更新予定年は未確認のため推測値を掲載しない。全国・隣県の同定義値がない機器も同列比較しない。

地震・津波・停電・断水・通信障害・航路停止などの複合リスクに備え、CT/MRIの復旧手順、超音波・POCUSの代替、患者搬送・部品物流・保守員派遣経路を設計する。[S22]

瀬戸大橋を含む本州・四国物流と、小豆島航路は別の障害シナリオとして検討する。

人材と機器供給の制約

医師・技師・看護師の不足、調達リードタイム、半導体、ヘリウム、災害時物流、サイバーリスクを考慮。海外供給依存度や地域固有の実害は統計がない限り断定しない。

反対仮説とリスク

①CT/MRIの配置密度が高く新規機器需要が限られる可能性、②人口減と資金制約で更新延期、③共同利用促進で新設件数が減る可能性、④島内需要が小さく高コストの遠隔支援が単体採算を取りにくい可能性。

SWOT — 市場全体

Strengths / 強み

高松と西部の基幹医療ネットワーク、CT/MRI配置密度、大学病院・がん・救急拠点。

Weaknesses / 弱み

人口減少、地域医師格差、離島の保守・搬送制約、投資回収期間の長期化。

Opportunities / 機会

画像共有、共同利用、診療所US/POCUS、在宅・回復期・病診連携、BCP更新。

Threats / 脅威

診療報酬・物価・人材・供給網・サイバー・災害による設備投資余力と稼働への影響。

PEST → 3C → STP → 4P → 4C → VRIO → 5 Forces（体系化）
フレーム香川の分析次の実証指標
PEST医療計画・報酬／高齢化・人口減／人手不足／画像共有と遠隔医療。病床機能推移、65歳以上、医師数、医療DX稼働
3CCustomer：病院・診療所・患者の機能別需要。Competitor：複数供給・共同利用。Company：医療商社としての中立調達と保守。検査件数、稼働、保守人員・対応時間
STPSegment：東部高度医療／西部広域連携／小豆離島。Target：検査の待機・停止・搬送負担が大きい機能。Position：導入から稼働まで支える商社。患者移動、検査待ち日数、停止時間
4PProduct：装置+IT+教育+保守。Price：TCO/稼働当たり。Place：拠点・共同利用・訪問保守。Promotion：臨床根拠と透明な調達情報。5年TCO、可用性、到達時間
4CCustomer value：適時診断。Cost：初期費用+管理負担。Convenience：共同利用・遠隔連携。Communication：病院、医師会、患者への双方向説明。患者移動負担、予約状況、教育・満足度
VRIO価値・希少性・模倣困難性・組織適合：地域全体の保守網、メーカー横断の臨床支援、災害時の代替供給力を検証。SLA、共同利用導入実績、代替機訓練
5F既存競争・新規参入・顧客交渉力・供給者交渉力・代替（紹介・共同利用・移動型・遠隔）を同時評価。入札競争、共同利用率、供給遅延、代替手段

KSF / Key Success Factors

  1. 医療圏・病院機能別の検査需要の一次情報把握
  2. CT/MRI/USの稼働・検査件数とTCOの可視化
  3. 医師会・大学・行政・病院を結ぶ共同利用・病診連携
  4. 離島と広域市場での保守BCPと代替機運用
  5. 装置・IT・教育・資金・更新工程の一体提案
  6. 出典・推計・事実を区別した透明性

90日 / 1〜3年の実行ロードマップ

0〜30日：県計画・病床機能・装置施設別データの台帳化、重点医療機関・診療科・技師配置を地図に重ねる。

31〜60日：東部と西部で検査共同利用・紹介動線を確認。小豆は停電・航路停止・遠隔読影のBCPヒアリング。

61〜90日：3地域で「稼働率・待機日数・TCO・停止時間」を共通KPIとしてPoCを選定。

1〜3年：機器更新と地域連携IT・遠隔保守を統合し、医療アクセスと財務持続性を定期評価。

失敗する戦略： CT・MRIの人口当たり台数だけで不足地域を決める／公開されていないメーカーシェアを推測する／補助金を採択確定として扱う／医療圏境界を越える患者移動を無視する／投資後の人員・保守・稼働を評価しない。これらは避ける。

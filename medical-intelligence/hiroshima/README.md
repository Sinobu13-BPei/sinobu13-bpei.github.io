## 出典・計算方針

- 2025年国勢調査 **確報** の県人口は 2,682,786 人、65歳以上人口は 818,519 人、23市町の集計もこの資料に準拠（広島県 2026-09-29公表）。[原資料](https://www.pref.hiroshima.lg.jp/uploaded/attachment/683199.pdf)
- 2026-09-01 推計人口は 2,675,196 人（広島県 2026-10-21公表）。ただし2020年国勢調査を起点とした月次推計であり、2025年確報を起点とした遡及改定予定。数値を混算しない。[人口推移](https://www.pref.hiroshima.lg.jp/soshiki/21/jinkougeppojinkousuiisaisin.html)
- 2025年7月1日病床機能報告 29,606 床（休棟等1,138床含む）。2025年必要病床数 28,614 床は別の地域医療構想の推計値で、病棟の報告機能とは定義・調査時点が異なる。[病床機能報告](https://www.pref.hiroshima.lg.jp/soshiki/54/reiwa07.html)
- 2030年開院の新病院・福山市民病院などの設備計画は、公表時点の計画であり変更可能。
- 暫定スコアは、需要 30%、再編 25%、アクセス課題 20%、連携 15%、実装性 10% の5尺度（各1〜5点）を重み付き合算して20倍。公的な行政評価ではない。

## 公開できないもの／継続照合

- 非公開資料の販売会社シェア、商談情報、取引条件、個人名・案件名を公開版に転載しない。
- CT/MRI/US/PET/放射線治療などの県全体の保有台数と人口当たり装置台数の全国比較は、2025年度病床機能報告の施設票・医療施設調査・医療機能情報から同一母集団で集計する必要があり、未検証の数字を代入しない。
- 2025年必要病床数の7圏域ごとの内訳は、県の地域医療構想比較表から再集計が必要。
- 医療機能の最新指定、医師多数/少数区域、医師会・保健所住所、全リンク応答は改訂時に確認する。
- 地図ピンのうち施設の参考座標が欠けるものは市域の概略座標である。GPS精度を保証しない。
- 医師偏在指標は2026年4月の都道府県別数値を採用し、人口10万人対医師数ではない。

## 確認方法

1. GitHub上で `index.html`, `css/style.css`, `js/app.js`, `data/hiroshima-data.js` が存在すること。
2. JavaScriptの構文、DOM要素との整合、出典URL・年次の有無を確認する。
3. 公開URLで Chart.js 4系、Leaflet 1.9.4、地理院タイルのロードを確認する（外部CDN依存）。
4. PC／375px程度のスマートフォンで見出し・表の横スクロール・地図操作を確認する。
5. Googleマップリンクと地理院地図リンクを数件抽出確認し、必要に応じて住所・概略座標を補正する。

免責：公開された情報に基づく独立研究。正確性・完全性・将来の成果を保証しません。

### QA・解釈上の重要点
- 各時点を混同しない。2020年国勢調査・2023年度DPC症例・2024年医師偏在旧版・2025年国勢調査・2025年病床機能報告は別時点。
- DPC比較の添付原文は「完結率」と呼ぶが、100%を超す場合がある。ここでは「所在地症例数/患者住所地症例数」の需給比と記し、地区内完結率そのものとは扱わない。
- 症例数は千件の小数第1位への丸めであり、公表比率を再計算で代替すると異なる（広島中央73.6%等）。公表比率をそのまま記録する。
- 民間調査の医療機器市場推計は病院・大学等向け末端市場で、SPD・消耗品等の取引を含む可能性があり、画像診断機器単独のTAMではない。
- 個社売上・取引条件・占有率・施設内顧客リスト・メーカー固有の売上戦略はWebに含めない。
- GitHubへの反映は実行済み。外部CDN/ページのHTTP配信・スマートフォン実機試験は別途確認を要する。
